## Intabia Platform API

Intabia Platform exposes a REST/WebSocket API for integrations and external applications. Access is granted through an API key — for how to issue one, and how an integration key differs from a personal key, see [API keys](/en/integrations/api-keys).

To receive events from external systems (including Prometheus, Grafana, GitLab, Sentry, or any other system that posts JSON), use [webhooks](/en/integrations/webhooks).
