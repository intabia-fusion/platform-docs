Intabia Platform supports the creation of diagrams using MermaidJS, a simple markdown-like language for generating diagrams and flowcharts. For specific syntax and examples of different kinds of diagrams you can create, see the [MermaidJS documentation](https://mermaid.js.org/intro/).

## Creating a diagram

To create a diagram in a document, type `/` and select `Diagram`. This inserts a code block right into the text where you can enter your MermaidJS code.

When valid MermaidJS code is entered, the diagram will automatically render in the space below. Collapsing the code editor (with the collapse icon) will leave only the diagram visible on the page — the code stays editable, just expand the block again.

## Viewing and editing a diagram

The diagram's code is edited right in the code block while it's expanded. To view the rendered image at full size, click it — the first click selects the diagram, and clicking it again while selected opens a full-size, view-only preview of the image.

> **Note:** Select a diagram and press the delete key to remove it from the document.
