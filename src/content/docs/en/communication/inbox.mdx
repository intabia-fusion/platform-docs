Open your inbox by clicking the bell icon in the main sidebar. A red dot at the corner of the icon indicates unread notifications.

The tabs in the top menu are built dynamically: the object types (channels, issues, documents and so on) you have notifications for show up, plus an **All** tab and a separate **Threads** tab for thread replies only; comments on issues, files and other objects show up under that object type's own tab. Turning on the `Unreads` filter narrows the list to objects with unread notifications.

Selecting a card in the inbox opens the object right there, in the same panel — a channel with its full message history, or an issue or document with its own activity.

<Shot src={hoverActions} alt="Inbox: the «marketing» channel open with the action toolbar on a message" />

Hover over any message to:
* add a reaction;
* reply in a thread;
* reply in the chat;
* save the message;
* translate it into the platform's interface language.

The `⋮` icon on a message opens more actions, including `Forward message` and `Pin`.

## Organizing your inbox

The settings icon (sliders) in the inbox header opens an `Unreads` toggle — turn it on to show only cards with unread notifications.

Next to it is the `⋮` icon with a menu for bulk actions: `Mark all as read` and `Clear all`.

Every card (a channel, document or issue) has a circular checkbox — click it to clear that whole card from your inbox. The `⋮` icon in a card's header opens a menu with `Mark as read` (unread cards only), `Clear`, or `Unsubscribe` from notifications about that object.
