Inline comments let you add a note, a question or feedback to a specific spot in the text — in a document or an issue description — without starting a separate chat message.

Inline comments differ from comments in the "Activity" section at the bottom of a document, issue or other platform object:

* **Purpose.** Activity comments work best for notes about the document or object as a whole. Inline comments are for pointing at a specific word, phrase or passage of text;
* **Link to chat.** Activity comments are connected to Chat, Inbox and notifications. Inline comments aren't linked to the rest of the platform — they don't trigger notifications today;
* **Lifespan.** Activity comments stay part of the object's history. Inline comments are meant for a short discussion: once the question is settled, the whole thread can be deleted at once.

## Adding a comment

Select some text — in a document or an issue description — and click the comment icon on the floating toolbar that appears (it sits next to the text formatting icons: headings, bold, italic and the rest).

<Shot src={selectComment} alt="Selected text in a document with the floating toolbar and the comment icon on the right" />

Type your comment and submit it — a comment thread appears next to the selection. To reply, type in the field at the bottom of the thread and submit — your reply is added to the same thread.

Text with a comment is highlighted in the document. When the window is wide enough, comment threads show up next to the text; in a narrower window, a thread only shows when you click the highlighted text.

## Resolving a thread

To resolve a discussion, hover over the first comment in the thread (at the top) and click the checkmark icon — `Resolve`.

> **Warning:** Resolving a thread **permanently deletes** every comment in it along with the text highlight — this cannot be undone.

## Editing and deleting

To edit or delete your own comment, hover over it and open the actions menu. `Edit` and `Delete` are available there; you can't edit someone else's comment.
