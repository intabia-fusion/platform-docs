"Интабия Платформа" поддерживает создание диаграмм с использованием MermaidJS — простого языка, похожего на markdown, для генерации диаграмм и блок-схем. Для получения информации о конкретном синтаксисе и примерах различных видов диаграмм, которые вы можете создать, см. [документацию MermaidJS](https://mermaid.js.org/intro/).

## Создание диаграммы

Чтобы создать диаграмму в документе, введите `/` и выберите `Диаграмма`. Прямо в текст добавится блок кода, в который можно ввести код MermaidJS.

При вводе корректного кода MermaidJS диаграмма автоматически отобразится в пространстве ниже. Сворачивание редактора кода (значком сворачивания) оставит на странице только видимую диаграмму, код при этом остаётся редактируемым — достаточно развернуть блок обратно.

## Просмотр и редактирование диаграммы

Код диаграммы редактируется прямо в блоке кода, пока он не свёрнут. Чтобы просмотреть саму картинку крупно, нажмите на неё — первый клик выделит диаграмму, повторный клик по уже выделенной диаграмме откроет её полноразмерный просмотр (только изображение, без редактирования).

> **Примечание:** Выделите диаграмму и нажмите клавишу "Delete", чтобы удалить её из документа.
