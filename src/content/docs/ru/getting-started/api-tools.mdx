## API "Интабия Платформа"

"Интабия Платформа" предоставляет REST/WebSocket API для интеграций и внешних приложений. Доступ к API выдаётся по API-ключу — о том, как его выпустить и чем интеграционный ключ отличается от личного, см. [API-ключи](/ru/integrations/api-keys).

Чтобы принимать события от внешних систем (включая Prometheus, Grafana, GitLab, Sentry и любые другие, присылающие JSON), используйте [вебхуки](/ru/integrations/webhooks).
