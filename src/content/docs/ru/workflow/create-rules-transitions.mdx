Переходим из настроек проекта в раздел workflow. Выбираем из списка нужный вариант и переходим на страницу , чтобы создать переходы между статусами. 

В правом верхнем углу страницы вы увидите:
1. Тип задачи, для которой будет применяться workflow,
2. Кнопки для переключения формата отображения: списком, диаграмма, разделенный экран,
3. Кнопка для экспорта workflow (экспорт файла или копирование в буфер обмена),
4. Кнопка удаления workflow. 

Начните создание переходов с поля "Начальные статусы" и выберите статус, который будет “точкой входа” в workflow . Затем нажмите кнопку “+” и создайте первый  переход. 

1. Напишите название 
2. В поле “Откуда” выберите требуемый статус
3. В поле “Куда” выберите требуемый статус
4. Нажмите кнопку “Создать”, чтобы сохранить переход.
5. Нажмите кнопку “Отмена”, чтобы отменить операцию.

Аналогичный образом создайте запланированное количество переходов. Все transitions отобразятся списком на странице.

После того как были созданы все переходы, зададим правила и условия проверки.

Нажмите на необходимый переход и в боковой панели откроются настройки. Вверху страницы указано название  перехода статусов и их маршрут (откуда-куда). Через кнопку “+” откроется модальное окно, чтобы добавить правила для запросов, валидаторов и пост-функций.

**Для запросов** в модальном окне нажмите на  “Показать экран” и из списка выберите ранее настроенный экран (см. описание “Создаем экраны”).  При необходимости отредактировать его, нажмите “Настроить экран”.  После того как экран добавлен, сохраните изменения с помощью кнопки “Добавить”.

Все заданные правила можно отредактировать или  удалить, если нажать на “три точки” в соответствующей карточке и выбрать требуемое действие. После того как все правила внесены, нажмите “Ок”, чтобы сохранить изменения. Настройка workflow завершена.

**Важно!**

Нельзя выбрать переход из одного и того же статуса в такой же, например Backlog → Backlog.

Нельзя создать дубль перехода, если подобный уже существует.
