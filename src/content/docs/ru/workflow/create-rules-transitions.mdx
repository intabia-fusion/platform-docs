Переходим: Настройки -> Типы пространств -> нужный тип проекта -> Воркфлоу. Выбираем из списка нужный workflow и переходим на его страницу, чтобы создать переходы между статусами.

В правом верхнем углу страницы вы увидите:
1. Тип задачи, для которой будет применяться workflow,
2. Кнопки для переключения формата отображения: списком, диаграмма, разделенный экран,
3. Кнопка для экспорта workflow (экспорт файла или копирование в буфер обмена),
4. Кнопка удаления workflow.

Импорт workflow — отдельная кнопка (значок рядом с `+`) в заголовке раздела "Воркфлоу" настроек типа проекта, а не на странице самого workflow: можно импортировать из файла или из буфера обмена.

Начните создание переходов с поля "Начальные статусы" и выберите статус, который будет “точкой входа” в workflow . Затем нажмите кнопку “+” и создайте первый  переход. 

1. Напишите название 
2. В поле “Откуда” выберите требуемый статус
3. В поле “Куда” выберите требуемый статус
4. Нажмите кнопку “Создать”, чтобы сохранить переход.
5. Нажмите кнопку “Отменить”, чтобы отменить операцию.

Аналогичный образом создайте запланированное количество переходов. Все transitions отобразятся списком на странице.

<Shot src={transitions} alt="Список переходов workflow: откуда и куда ведёт каждый" />

После того как были созданы все переходы, зададим правила и условия проверки.

Нажмите на необходимый переход и в боковой панели откроются настройки. Вверху страницы указано название  перехода статусов и их маршрут (откуда-куда). Через кнопку “+” откроется модальное окно, чтобы добавить правила для запросов, валидаторов и пост-функций.

**Для запросов** в модальном окне нажмите на  “Показать экран” и из списка выберите ранее настроенный экран (см. описание “Создаем экраны”).  При необходимости отредактировать его, нажмите “Настроить экран”.  После того как экран добавлен, сохраните изменения с помощью кнопки “Добавить”.


<Shot src={rules} alt="Правило запроса «Показать экран» с выбранным экраном" />

**Для валидаторов** в модальном окне задаются 3 правила:

1. Проверить данные обязательного поля

Нажмите параметр “Обязательное поле” и выберите поле из списка для проверки . Сохраните внесенные изменения.  

<Shot src={field} alt="Валидатор «Обязательное поле» с выбором поля для проверки" />

   
2. Проверить статусы подзадач

Нажмите на параметр “Статус подзадач” и выберите соответствующий статус для каждого типа задач. Сохраните изменения.

<Shot src={status2} alt="Валидатор «Статус подзадач» по типам задач" />

3. Проверить статусы родительских задач

Нажмите на параметр “Статус родительской задачи” и выберите соответствующий статус для каждого типа задач. Сохраните изменения. 

<Shot src={status1} alt="Валидатор «Статус родительской задачи» по типам задач" />

**Для пост-функций** в модальном окне настраиваются 2 правила:

1. Обновить значение поля

Нажмите параметр “Обновление значения поля”, выберите поле из списка и  значение, которое нужно установить. Если следует обновить значение для нескольких полей, нажмите “Добавить” и повторите алгоритм предыдущих шагов. Затем сохраните изменения.  

<Shot src={update} alt="Пост-функция «Обновление значения поля»" />

2. Очистка полей

Нажмите параметр “Очистка полей”, выберите поле для очистки из списка и сохраните изменения. 

<Shot src={clearing} alt="Пост-функция «Очистка полей»" />

Все заданные правила можно отредактировать или  удалить, если нажать на “три точки” в соответствующей карточке и выбрать требуемое действие. После того как все правила внесены, нажмите “Ок”, чтобы сохранить изменения. Настройка workflow завершена.

**Важно!**

Нельзя выбрать переход из одного и того же статуса в такой же, например Backlog → Backlog.

Нельзя создать дубль перехода, если подобный уже существует: дублем считается переход с тем же статусом "Куда" при пересечении статусов "Откуда" (в том числе если оба перехода заданы как "из любого статуса").
