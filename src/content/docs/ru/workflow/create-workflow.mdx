Для создания workflow:

1. Нажмите на значок “Аккаунта” внизу главного бокового меню;
2. В появившемся окне выберите раздел “Настройки”;
3. В левой боковой панели “Настройки” выберите раздел “Типы пространств” и нажмите «Классический проект»;
4. На странице отобразятся все настройки «Классический проект»;
5. Выберите “Воркфлоу” и нажмите на кнопку “+”, чтобы начать работу.

В боковой панели введите название для workflow и выберите тип задачи, которая будет использована. Сохраните внесенные настройки, созданный workflow отобразится в списке.
