В карточке раздела **“Типы задач”** каждому типу задаем статусы используемые в workflow. Для этого выбираем тип задачи и переходим в секцию “состояния процесса”.  
В карточке по умолчанию уже добавлены 5 статусов, соответствующие категориям:

- Backlog (пул задач),
- To do (не запущенные),
- In progress (активные),
- Done (завершено),
- Canceled (завершено).

Чтобы добавить дополнительные статусы нажмите на “+ “, затем напишите название статуса и его описание, выберите категорию статуса и цветовую индикацию, после чего сохраните изменения. 

В правом верхнем углу вы можете редактировать состояние, т.е удалять и копировать статусы, нажав на кнопки с соответствующими иконками.
