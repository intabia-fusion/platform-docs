## Что такое проекты?

Проекты — это всё, над чем будет работать ваша команда, и их можно организовать любым удобным для вас способом. Например, команда разработчиков программного обеспечения может разделить свою работу на проекты, такие как «Фронтенд», «Бэкенд», «UX/UI» и «Тестирование». Малый бизнес может создать проекты, такие как «Инвентарь», «Маркетинг» и «Дизайн». Однако вы можете настроить свои проекты любым способом — они просто представляют собой отдельные пространства, которые будут содержать ваши задачи.

## Создание проекта

#### Добавление проекта:
1. Нажмите на Трекер в левом меню. Убедитесь, что боковая панель открыта, нажав на горизонтальные линии в верхнем левом углу.
2. Нажмите значок `+`, который появляется при наведении на «Проекты» на боковой панели, или нажмите выпадающее меню рядом с кнопкой `+ Новая задача` и выберите `Новый проект`. 
3. Откроется диалоговое окно, где вы можете ввести начальные настройки для вашего проекта. После ввода желаемых настроек нажмите `Создать`.

## Настройки проекта
При создании или редактировании проекта вы можете настроить следующие параметры:

**Тип проекта**: Тип проекта по умолчанию — `Classic project` (название не переводится). Вы можете создавать собственные типы проектов в настройках рабочего пространства.

**Название проекта**: Название вашего проекта.

**Идентификатор**: Аббревиатура, используемая для идентификации задач, созданных для этого проекта. Она автоматически генерируется при вводе названия проекта, но может быть изменена.

**Описание**: Описание вашего проекта.

**Выбрать иконку**: Выберите иконку для представления вашего проекта — либо стандартную иконку с пользовательским цветом, либо эмодзи.

**Исполнитель задачи по умолчанию**: Выберите участника, которому вы хотите назначать задачи по умолчанию.

**Статус по умолчанию**: Выберите статус, который все новые задачи должны иметь по умолчанию при создании.

**Владельцы**: Выберите владельца проекта, который будет иметь права на редактирование деталей проекта.

**Сделать личным**: Переключите, если хотите, чтобы этот проект был виден только участникам.

**Участники**: Выберите всех участников этого проекта.

**Автоприсоединение**: Переключите, если хотите, чтобы новые участники автоматически добавлялись в этот проект.
