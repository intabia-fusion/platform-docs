## Представления списком и канбан

Представление задач по умолчанию — это представление задач списком, где они перечислены в порядке их статуса. В "Интабия Платформа" также есть возможность канбан-представления, которое отображает задачи в формате плашек и столбцов. Чтобы переключаться между двумя представлениями, нажмите на значок списка или канбана в левом верхнем углу окна над списком задач.

## Быстрый просмотр задачи

Нажмите клавишу `пробел`, наведя курсор на любую задачу, чтобы открыть детали этой задачи в боковой панели. При открытых деталях задачи вы сможете использовать клавиши вверх и вниз на клавиатуре для прокрутки ваших задач. Повторное нажатие на пробел закроет панель.

Наведение курсора на комментарии или сроки выполнения также откроет предпросмотр этих деталей.

## Сочетание клавиш

Нажмите `С` на клавиатуре, чтобы создать новую задачу из любого представления Трекера.

## Сортировка, фильтрация и поиск

Опции сортировки и фильтрации задач также находятся в левом верхнем углу. Кнопка `Группировка и сортировка` позволяет настроить параметры группировки и порядка задач на странице, а также переключатели `Подзадачи`, `Показывать пустые группы`, `Скрыть архивные` и `Использовать цвета`. Кнопка `Настроить отображение` отображает список колонок, которые показываются в представлении (приоритет, компонент, этап и другие).

<Shot src={toolbar} alt='Панель инструментов списка задач' />

Кнопка `Фильтр`, рядом с панелью поиска, открывает опции для фильтрации задач. Панель поиска можно использовать для поиска конкретной задачи по ключевому слову.

Для быстрой сортировки выберите `Активные`, `Пул задач` или `Все` — эти вкладки находятся в той же строке, что и панель поиска и фильтр, с правого края.

## Дорожка (Swimlane)

Дорожка (Swimlane) - визуальный инструмент горизонтальной группировки задач на канбан-доске: каждая дорожка - горизонтальная полоса по выбранному значению поля (исполнитель, приоритет и т.д.), что наглядно показывает распределение задач по этому полю.

В меню `Группировка и сортировка` -> `Дорожка` можно выбрать группировку по:

* Исполнителю;
* Приоритету;
* Компоненту;
* Этапу;
* Статусу;
* Родителю;
* Проекту.

В списке нет поля, по которому уже сгруппированы колонки доски: например, при группировке колонок по статусу (по умолчанию) варианта `Статус` не будет.
