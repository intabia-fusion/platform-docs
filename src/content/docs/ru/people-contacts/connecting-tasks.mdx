---
title: Связывание задач
description: Узнайте, как связывать задачи с вашими контактами.
---

Задачи в вашем рабочем пространстве могут быть напрямую связаны с сотрудниками в вашем списке контактов. Есть несколько случаев, когда это может быть полезно, например:

- **Работа с сотрудником** — связывайте задачи в Трекере с контактом сотрудника, чтобы быстро видеть, кто отвечает за конкретный вопрос, и отслеживать, с кем связаться за обновлением, обратной связью или согласованием.

- **Планирование последующих контактов** — отслеживайте договорённости о повторном разговоре, создавая в Трекере задачи, связанные с контактом сотрудника. Ведите записи о взаимодействиях и устанавливайте напоминания о том, когда связаться повторно.

- **Отслеживание внутренних запросов** — если сотрудник обратился с запросом, свяжите задачу с его контактом. Это позволяет легко увидеть все задачи, связанные с этим человеком, и отслеживать их статус.

## Создание новой задачи

Чтобы создать задачу из контакта, кликните на него правой кнопокой мыши и выберите `Завести связанную задачу`. Откроется диалоговое окно для создания новой задачи.

После создания задачи в блоке «Связано с задачами» под описанием появится эта задача. Здесь вы можете увидеть контакт, связанный с этой задачей.

## Просмотр связанных задач

Чтобы просмотреть все задачи, связанные с контактом, перейдите в Трекер и выберите `Все задачи`. Используйте кнопку `Фильтр`, чтобы выбрать `Связано`, а затем выберите имя контакта, задачи которого хотите увидеть.
